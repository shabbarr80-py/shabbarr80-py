## Getting Started

### Prerequisites

### Installation
```bash
# Clone the repository
git clone https://github.com/shabbarr80-py/project-name.git
cd project-name

# Frontend
cd frontend
npm install
npm run dev

# Backend (new terminal)
cd backend
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
```
